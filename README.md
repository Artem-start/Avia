# Курсовой проект — «Приложение для продажи билетов на рейс»

## Технологии
- C#, Windows Forms, .NET 8, Visual Studio 2022 (рабочая нагрузка «Разработка классических приложений .NET»)
- Хранение данных в JSON локально, без сервера и дополнительных NuGet-пакетов.
- Пароли хранятся в виде PBKDF2-хешей с индивидуальными salt, не в открытом виде.

## Запуск
1. Распакуйте ZIP-архив.
2. Откройте `FlightTickets/FlightTickets.csproj` в Visual Studio 2022.
3. Установите .NET 8 SDK и компонент «Разработка классических приложений .NET», если Visual Studio попросит.
4. Нажмите F5 или кнопку «Запустить».
5. Для демонстрации прав администратора войдите: **admin** / **Admin123!** (после сдачи смените демонстрационный пароль, если будете развивать проект).
6. Для демонстрации покупки зарегистрируйте обычного пассажира.

## Возможности
- Регистрация и вход пользователя; роли «Пассажир» и «Администратор».
- Поиск по городам, дате, просмотр доступных мест, маршрута и цены.
- Оформление билета с данными пассажира, назначение свободного места, демонстрационная оплата.
- История билетов, открытие и сохранение электронного билета как TXT, отмена до вылета.
- Добавление, редактирование и удаление рейсов администратором; статистика продаж.
- Сохранение данных между запусками в `%LOCALAPPDATA%\FlightTicketsCourse\data.json`.

## Важно
**Это учебный прототип**, а не система настоящих авиаперевозок: рейсы вымышленные, оплата имитируется, выданный билет не дает права на посадку, нет подключения к системам авиакомпаний. Номер документа хранится локально в учебном файле данных — для демонстрации используйте только вымышленные данные. Не применяйте его для реальных продаж.

## Про структуру
- `Program.cs` — точка входа.
- `Models.cs` — классы пользователь, рейс, билет.
- `DataStore.cs` — сериализация, вход, тестовые рейсы.
- `MainForm.cs` — интерфейс и обработчики событий Windows Forms.

## Порядок демонстрации на защите
1. Запустить приложение, показать таблицу рейсов и фильтры.
2. Зарегистрировать нового пассажира.
3. Выбрать рейс и купить билет (имитация оплаты).
4. Открыть вкладку «Мои билеты», сохранить электронный билет.
5. Выйти и зайти под учетной записью администратора.
6. Добавить новый рейс и показать статистику.
7. Перезапустить программу и показать, что данные сохранились.

## Где изменить тестовые рейсы
Метод `SeedFlights()` файла `DataStore.cs` генерирует учебное расписание для первых 15 дней после первоначального запуска. При повторном запуске расписание не пересоздаётся. Администратор может добавлять новые рейсы. Для полного сброса тестовых данных можно удалить файл `%LOCALAPPDATA%\FlightTicketsCourse\data.json` (все пользователи и билеты при этом будут утрачены).
